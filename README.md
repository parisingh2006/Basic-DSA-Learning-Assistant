## 🎯 Project Overview

**Smart DSA Learning & Problem-Solving Assistant** is a console-based C++ application developed as a Semester 3 Project-Based Learning (PBL) project.

The system combines **DSA learning, topic-wise practice, performance analysis, recommendations, and interactive data structure implementations** into one structured learning environment.
